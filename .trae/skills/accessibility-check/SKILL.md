# Accesibilidad (A11y)

- Objetivo: asegurar mínimo WCAG AA en contraste y navegación por teclado.
- Entradas: páginas y componentes clave (botones, links, formularios).
- Salida: reporte + parches CSS/HTML para contraste, foco y roles.
- Ejecución (MCP): ejecutar tras el refactor para validar accesibilidad; revisar foco visible en toda la UI.
