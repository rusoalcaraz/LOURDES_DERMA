# Auditoría Visual UI

- Objetivo: diagnóstico visual integral del sitio (estética, consistencia y calidad).
- Entradas: rutas a `index.html`, `styles.css`, carpeta `assets/`; paleta/tipografías deseadas.
- Áreas: tipografía, color, espaciado, jerarquía visual, responsive, contraste, foco visible.
- Salida: reporte con hallazgos priorizados y lista de cambios accionables (con ejemplos).
- Ejecución (MCP): iniciar página local, revisar estructura, validar estados, anotar hallazgos y proponer diffs.
