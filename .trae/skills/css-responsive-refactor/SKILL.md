# Refactor CSS Responsive

- Objetivo: organizar CSS, aplicar tokens y establecer layout responsive mobile-first.
- Entradas: `styles.css` y secciones objetivo (hero, cards, nav, footer).
- Salida: diff sugerido más utilidades y media queries claras.
- Ejecución (MCP): indicar componentes prioritarios y puntos de quiebre deseados; validar en distintas anchuras.
