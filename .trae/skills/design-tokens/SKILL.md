# Tokens de Diseño

- Objetivo: crear variables CSS y utilidades base coherentes con la marca.
- Entradas: paleta de color (hex), familias y escala tipográfica, espaciado, radio y sombras.
- Salida: bloque CSS con `:root` y guía de uso; mapping sugerido para reemplazar valores directos.
- Ejecución (MCP): insertar bloque en `styles.css`, verificar componentes clave y proponer reemplazos.
